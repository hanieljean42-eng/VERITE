# Vérité — Chat Wrapped & Red Flag Detector

Analyse tes conversations WhatsApp pour découvrir la vérité. Red flags, scores d'intérêt, compatibilité, toxicité et bien plus.

## Fonctionnalités

- **Score global /100** — Un verdict clair sur ta relation
- **Détection de red flags** — Ghosting, manipulation, désintérêt...
- **Green flags** — Ce qui va bien aussi
- **Scores détaillés** — Effort, compatibilité, intérêt, toxicité
- **Patterns temporels** — Quand vous parlez le plus
- **Citations marquantes** — Les messages les plus importants
- **Jalons relationnels** — Premier message, premier "je t'aime"...
- **Conseils personnalisés** — Recommandations adaptées à ta situation
- **Mode comparaison** — Compare 2 conversations
- **Partage en Story** — Génère une image stylée de tes résultats
- **Dark mode** — Mode sombre profond
- **Historique** — Retrouve tes analyses précédentes
- **PWA** — Installable sur téléphone

## Confidentialité

**100% client-side.** Aucune donnée ne quitte ton appareil. Zéro serveur, zéro tracking, zéro compte.

## Stack technique

- Next.js 14 (Static Export)
- TypeScript strict
- Tailwind CSS
- PWA (Service Worker)
- Déployé sur Netlify

## Développement

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Le site est exporté en statique dans le dossier `out/`.
